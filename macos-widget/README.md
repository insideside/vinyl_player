# Vinyl Player — виджет на рабочий стол (macOS)

Виджет для [Übersicht](https://tracesof.net/uebersicht/), который управляет
локальным сервером Vinyl Player (`vinyl_player.py`).

## Возможности

- **Включение/отключение приложения** — переключатель в шапке запускает сервер
  в фоне (`nohup python3 vinyl_player.py …`) и останавливает его (`pkill`).
- **Управление плеером** — когда приложение включено и плеер открыт в браузере:
  кнопки ⏮ / ⏯ / ⏭ и вывод имени текущего трека (исполнитель + название).
- **Открыть плеер в браузере** — кнопка со стрелкой.
- **Темы интерфейса** — кружок в шапке циклически переключает:
  `auto` (следует за системной светлой/тёмной темой) → `dark` → `light` →
  `transparent`. Выбор запоминается.

## Как это работает

Воспроизведение живёт в браузере (`<audio>` + MediaSession). Чтобы виджет мог
показывать трек и управлять плеером, в `vinyl_player.py` добавлен мост
(только для localhost, без авторизации):

| Endpoint | Кто вызывает | Назначение |
|---|---|---|
| `POST /api/widget/state`   | браузер | публикует «сейчас играет» |
| `GET  /api/widget/state`   | виджет  | читает трек + статус |
| `POST /api/widget/command` | виджет  | ставит команду (play/pause/toggle/next/prev) |
| `GET  /api/widget/command` | браузер | забирает и выполняет команду |

Виджет каждые 1.5 с опрашивает состояние и проверяет, запущен ли процесс
(`pgrep -f vinyl_player.py`). Поддерживаются и HTTPS (LAN-режим, самоподписанный
сертификат), и обычный HTTP — виджет пробует https, затем http.

## Установка (в т.ч. на новом Mac)

Скопируйте папку проекта на новый Mac и запустите **один файл** — двойным
кликом в Finder:

```
macos-widget/setup.command
```

(или из терминала: `bash macos-widget/setup.command`)

Установщик сам, под пути именно этой машины:

1. поставит **Homebrew** (если его нет; может запросить пароль);
2. поставит **Übersicht** (хост для виджетов);
3. создаст **venv** `.venv/` в проекте и поставит зависимости из
   `requirements.txt` (`httpx`, `mutagen`, `vkpymusic`, `musicbrainzngs`,
   `Pillow`, `cryptography`);
4. установит виджет в `~/Library/Application Support/Übersicht/widgets/`,
   **подставив актуальные пути** (Python из venv, путь к `vinyl_player.py`).

Скрипт можно запускать повторно — он обновит зависимости и починит установку.

## Настройка

Обычно ничего править не нужно — `setup.command` подставляет пути сам.
Если запускали виджет вручную, пути задаются вверху
`vinyl-player.widget/index.jsx` (`PY`, `APP`, `LOG`). Позицию на экране задают
`top` / `left` в блоке `className` того же файла.

## Замечания

- Эндпоинты виджета доступны **только с localhost** — даже при включённом
  LAN/WAN режиме они не видны из сети.
- Управление (⏮/⏯/⏭) работает, только пока вкладка плеера открыта в браузере —
  именно она выполняет команды. Если вкладка закрыта, виджет покажет
  «Плеер не открыт» и кнопку «Открыть плеер».
